# 飞书日报卡片展示

卡片由 send_digest.py 生成，展示配置为 card_layout.json。

- 默认显示标题、日期、扫描统计和开头主线摘要。
- 四个方向的正文及其来源链接放进“展开阅读完整日报”折叠面板，默认收起，读者点击后展开。
- collapse_body 设为 false 可以恢复全文直接显示；panel_title 可修改展开提示。
- 后续定时推送直接使用此配置，无需重建机器人。已经发出的旧消息不会自动变化。
- 生成原始日报时继续遵守 writing-skills/日报语言要求.md；折叠只影响卡片呈现，不删除正文。

依据：https://open.feishu.cn/document/feishu-cards/card-components/containers/collapsible-panel
