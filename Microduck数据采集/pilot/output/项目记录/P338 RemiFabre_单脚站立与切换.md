# RemiFabre · 单脚站立与切换

这个项目由 RemiFabre 制作，让机器鸭按指令抬起左脚或右脚，保持单脚站立，再放下恢复双脚站立。作者公开了模型文件、演示视频、控制程序和运行步骤。[项目说明](https://huggingface.co/RemiFabre/microduck-flamingo-cycle)

作者报告，同一模型可以切换左右脚，抬脚约9厘米，保持10秒以上，抬起或放下大约需要1.5秒。这些是作者给出的仿真结果，不是我们复现实验所得。作者明确写了尚未在实体机器上运行；虽然同时提供了实体部署步骤，也不能因此认定已经实机成功。

主要问题是受推后的稳定性。作者说明，受到较大的向后扰动时会摔倒，在24次随机试验中出现2次；另一个问题是，脚落地后，只要抬脚指令还在，模型就会再次抬脚。作者给出了操作上的处理方法：想让它稳定停在双脚状态，需要取消抬脚指令。这属于控制注意事项，还不能算已经修复了抗扰动问题。[具体限制与操作方法](https://huggingface.co/RemiFabre/microduck-flamingo-cycle/blob/main/README.md)
