# xgoduck_hardware

P425 · 硬件复刻与适配 · 作者：LuwuDynamics

这个项目由Luwu Dynamics制作，沿用机器鸭的双足结构，改用Arduino UNO Q和15个飞特舵机，并公开打印文件、电路、零件清单和装配手册。配套运行仓库负责标定和控制，训练仓库负责动作实验；它们属于同一套XGO-Duck方案，不应各算一个独立硬件产品。当前说明中的扩展板版本是V1.1，日期为2026年10月26日。[项目说明](https://github.com/LuwuDynamics/xgoduck_hardware)

公开资料已经有原型照片和翻身动作展示，但跟做者仍在卡具体环节：默认姿态和舵机零位缺少清楚对照，部分地区买不到指定舵机，电池选型和PCB制造文件也有人追问。作者回复称已更新部分电路文件，但有使用者继续请求经过验证的制造资料，因此不能把公开文件直接等同于普通人能顺利造出来。[零位问题](https://github.com/LuwuDynamics/xgoduck_hardware/issues/11)、[制造文件请求](https://github.com/LuwuDynamics/xgoduck_hardware/issues/10)

使用者还询问摄像头为何缺失；作者表示正在评估下一版的摄像头、麦克风、音频和距离感知。这是后续计划，不是当前功能已经具备。我们补查了最近30天的问题和回复，未亲自装配，也没有得到可统计的独立复现成功率。[作者回复](https://github.com/LuwuDynamics/xgoduck_hardware/issues/9#issuecomment-6063967153)

2026年10月29日首次入表并列入重点：价值在于不同主控方案下的成套硬件与软件路径，以及跟做者已经出现的具体问题。Star按当天API快照记录在总表，不把Star当销量。
