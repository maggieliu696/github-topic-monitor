# MicroDuck BoBoRedesign｜把鸭子的外壳和结构改得更适合 3D 打印

名单选择号：115。方向：自己组装、换零件和调试。作者／发布账号：**aibobomaker**。资料整理日期：2026 年 10 月 26 日。

## 项目做什么

BoBoRedesign 面向有 3D 打印机的制作者，重新整理外壳、承重结构、电路板和采购资料，并分别提供原版 XL330 与飞特 HD-1910 两种结构方案。 [项目说明](https://github.com/AiBoBoMaker/MicroDuck-BoBoRedesign)

代码或制作资料已在 GitHub 公开。**Star：12**，采集于 2026-10-26 16:43（北京时间）。原文称各部分已更新，但未给出可统一核对的整机版本；本次未核实最新发行版。 [仓库数据](https://api.github.com/repos/AiBoBoMaker/MicroDuck-BoBoRedesign)

## 目前做到哪一步

作者介绍，外壳、HAT 驱动板和姿态传感器模块已更新，仓库包含打印文件、板图、物料清单和调试工具。设计参考了 Microduck-kissqy，并希望降低复刻门槛。 [项目说明](https://github.com/AiBoBoMaker/MicroDuck-BoBoRedesign)

**当前判断：**它是面向制作者的结构与硬件资料项目。后续重点看别人打印后是否装得上、哪些地方需要返工，以及整机验证进度。

## 遇到了什么问题，怎样处理
