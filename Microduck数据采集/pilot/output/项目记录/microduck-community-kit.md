## 项目做什么

jyg9 为 Microduck 复刻提供身体姿态传感器板、电池转接板、集线板及相关固件，也维护飞特电机调试工具和官方运行程序的适配版本。 [项目说明](https://github.com/jyg9/microduck-community-kit)

代码或制作资料已在 GitHub 公开。**Star：23**，采集于 2026-10-26 16:43（北京时间）。飞特运行程序基于官方 0.16.0；XL330 路线作者建议 firmware-1.5.1，不能只按版本数字更大选择固件。 [仓库数据](https://api.github.com/repos/jyg9/microduck-community-kit)

## 目前做到哪一步

README 说明可在线升级固件，主要在 Linux 上开发，飞特适配基于官方 0.16.0。对于官方 XL330 路线，作者在 10 月 16 日回复称已有多位用户实测，建议保留 firmware-1.5.1，并提供读取和升级版本的方法。 [项目说明](https://github.com/jyg9/microduck-community-kit)

**当前判断：**这是复刻中比较具体的配套环节，已经有功能请求和作者后续回应。仍需把‘作者转述用户测通’与可独立复现的完整记录分开。

## 遇到了什么问题，怎样处理

此前有人指出固件缺少官方默认使用的高速读取功能，可能导致整组设备等待超时。作者先提交代码并请别人帮助测，因为当时没有 XL330 电机；后续回复才报告已有用户验证。作者同时说另一 FT6 配置的兼容性尚未实测。本轮没有独立核验其所引微信视频与完整设备版本清单。 [高速读取支持请求](https://github.com/jyg9/microduck-community-kit/issues/1) · [作者对实测和配套版本的回复](https://github.com/jyg9/microduck-community-kit/issues/2)
