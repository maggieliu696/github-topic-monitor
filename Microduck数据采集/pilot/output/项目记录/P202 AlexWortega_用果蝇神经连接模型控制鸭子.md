# AlexWortega · 用果蝇神经连接模型控制鸭子

这个项目由 AlexWortega 制作，尝试把果蝇神经连接的计算模型接到机器鸭上，让鸭子朝目标前进、转向和停止。简单说，它研究的是“怎么决定往哪走”；负责关节动作的行走能力仍来自已经训练好的鸭子模型，并不是果蝇模型从零学会了走路。[项目说明](https://huggingface.co/spaces/AlexWortega/flywire-microduck)

作者报告，在100个未用于训练的目标测试中，鸭子成功到达95个，且没有摔倒；移除神经信号或打乱部分特征后，几个对照测试均为0次成功。这些结果来自作者的模拟实验，我们没有独立复现，也没有证据证明它比其他控制方法更好。

作者明确指出：感官输入如何对应、神经信号如何计算等都包含人为设定；当前结果不能证明它与真实果蝇的大脑等价，也不能证明在实体机器鸭上同样有效。公开说明没有提供实体部署成功记录或使用者评价，暂时不能评价真实产品体验。

2026年10月27日首次建档：公开快照有9个点赞。由于用途和通常的动作训练不同，且给出了测试和边界，列入重点观察。后续关注是否有更多对照验证，以及能否搬到实体鸭子上。
