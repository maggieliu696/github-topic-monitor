# microduck-rl-genesis｜让 AMD 显卡也能训练鸭子走路

名单选择号：1。方向：教鸭子做动作。作者／发布账号：**macmachi**。资料整理日期：2026 年 10 月 26 日。

## 项目做什么

把官方主要依赖 NVIDIA 的行走训练迁到支持 AMD 的 Genesis。作者认为，官方公开的训练方法比具体代码更有价值，因此尽量保留电机、延迟和动作接口的设定。 [项目说明](https://github.com/Macmachi/microduck-rl-genesis)

代码或制作资料已在 GitHub 公开。**Star：6**，采集于 2026-10-26 16:43（北京时间）。本次按公开训练说明建档，未核实最新正式发行版。 [仓库数据](https://api.github.com/repos/Macmachi/microduck-rl-genesis)

## 目前做到哪一步

已提供安装、训练、回放和导出流程，并记录 AMD 设备上的训练结果。当前只迁移了上游的一类核心任务：速度控制行走，包含平地、粗糙地面，以及是否考虑齿轮间隙的组合。 [项目说明](https://github.com/Macmachi/microduck-rl-genesis)

**当前判断：**已经形成一条可研究的 AMD 训练路线，但当前完成范围是模拟行走。后续重点看实体部署和长时间对照结果。

## 遇到了什么问题，怎样处理

Genesis 与 MuJoCo 的接触计算不同，短时对照接近并不能保证长时间动作一致。作者明确说，这个仓库训练出的动作还没有部署到实体 Microduck；也未加入摄像头或激光感知，不能因此认为鸭子会自己避障。起身、踢球和轮滑等其他任务尚未迁入。 [项目说明](https://github.com/Macmachi/microduck-rl-genesis)
