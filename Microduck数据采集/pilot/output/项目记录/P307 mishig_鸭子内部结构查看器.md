# mishig · 鸭子内部结构查看器

这个项目由 mishig 制作，让人在网页里看机器鸭的零件、行走动作和拆开的结构。它主要帮助理解鸭子是怎么组成、怎么运动的，不是新的动作训练模型。[项目和说明](https://huggingface.co/spaces/mishig/microduck-anatomy)

目前公开说明介绍了交互式结构查看、局部零件聚焦和拆解视图。我们读到了说明，但还没有实际打开并逐项验证网页功能，也没有足够的使用者反馈来判断它是否真的降低了组装难度。作者在这份说明里没有列出具体故障、修复记录或版本号，不能把“未提到问题”理解成“没有问题”。
