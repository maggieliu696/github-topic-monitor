# MicroDuck Playground｜把荡秋千、踩球和高跷做成可复现的鸭子实验

名单选择号：14。方向：教鸭子做动作。作者／发布账号：**vottivott**。资料整理日期：2026 年 10 月 26 日。

## 项目做什么

在官方训练项目上继续尝试新动作，同时提供训练说明、动作模型、演示和可打印附件。GitHub 的实验与 Hugging Face 上发布的模型属于同一个项目，合并在这里跟踪。 [项目说明](https://github.com/Vottivott/microduck-playground)

代码或制作资料已在 GitHub 公开。**Star：74**，采集于 2026-10-26 16:43（北京时间）。说明中出现快跑 iteration-12,195 和高跷 Blend-0.50 等实验标记，它们不是整个项目统一的版本号。 [仓库数据](https://api.github.com/repos/Vottivott/microduck-playground)

## 目前做到哪一步

作者展示了荡秋千、踩篮球保持平衡、快跑、踩高跷和攀爬等实验。踩球模型不直接读取球的位置，作者报告其在 3,072 次、每次 60 秒的模拟测试中存活率为 97.01%；秋千实验报告摆动总幅度 173.20°。这些数字都来自作者的电脑模拟。 [项目说明](https://github.com/Vottivott/microduck-playground)

**当前判断：**适合观察新玩法怎样从演示变成可下载、可复做的实验。现阶段不能把丰富的动作视频理解为一套已经稳定可用的实体功能。

## 遇到了什么问题，怎样处理

作者明确说明，踩球、夹缝攀爬和部分跳跃等仍未做实体验证。绳结、支架变形、电机温度和装配误差尚不能由模拟结果替代。有人在问题帖里询问怎样录制演示视频，说明复现和展示方法也是使用门槛；帖子关闭本身不代表录制问题已得到用户确认。 [录制视频咨询](https://github.com/Vottivott/microduck-playground/issues/1)
