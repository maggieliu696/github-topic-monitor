# microduck-cli｜让人和 AI 用同一套命令操作鸭子

名单选择号：65。方向：让安装、控制和开发更容易。作者／发布账号：**agentculture**。资料整理日期：2026 年 10 月 26 日。

## 项目做什么

把启动环境、检查状态、调用动作和管理动作模型做成统一命令，让开发者和 AI 编程助手都能使用。 [项目说明](https://github.com/agentculture/microduck-cli)

代码或制作资料已在 GitHub 公开。**Star：7**，采集于 2026-10-26 16:43（北京时间）。0.9.4 是主要已记录的验证版本；0.9.6 出现在修复说明中，未据此认定它是最新发行版。 [仓库数据](https://api.github.com/repos/agentculture/microduck-cli)

## 目前做到哪一步

作者在三台计算设备上检查过命令、运行程序和 MuJoCo 模拟；记录中的主要核验版本为 0.9.4。工具已经能与控制程序通信，但作者同时明确写出尚不能正常走路、部分模型加载命令不兼容。 [项目说明](https://github.com/agentculture/microduck-cli)

**当前判断：**这是有明确能力边界的控制工具，还不能当作实体鸭子已经可用的统一遥控方案。后续要追踪走路故障、版本匹配和用户复测。

## 遇到了什么问题，怎样处理

移动指令能送到控制程序，返回的关节目标却不动；所用控制程序是 API 16，而部分加载命令要求 API 18。与其他大模型一起运行时还出现显存不足，暂停常驻模型后短程训练通过。另外 0.9.4 安装包漏带版本信息文件，检查页面一边写健康、一边显示失败；README 称 0.9.6 已修正，相关问题帖仍开放。 [安装包检查信息矛盾](https://github.com/agentculture/microduck-cli/issues/9)
