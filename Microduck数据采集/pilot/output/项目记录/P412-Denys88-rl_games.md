# rl_games

P412 · 动作训练与算法实验 · 作者：Denys88

rl_games由Denys88维护，是通用强化学习训练器。本轮关注的是它新增的MicroDuck训练路径：公开了运行配置、训练对比、动作展示和模型导出说明，而不是把整个框架的热度都当成机器鸭的热度。[项目说明](https://github.com/Denys88/rl_games)

作者报告，在相同任务环境和训练预算下，三次机器鸭实验的最终训练回报约148，对照训练器约120；达到对照最终水平所需时间约3分钟，对照约16.3分钟。这里的回报是训练任务评分，不是成功率；结果只适用于作者说明的硬件、参数和任务，我们没有独立复现，不能写成通用的五倍加速。[机器鸭训练与部署说明](https://github.com/Denys88/rl_games/blob/master/docs/MJLAB.md)

实际遇到的一个问题是数值精度会改变训练行为。作者的修复提案说明，使用bf16时，策略分布变窄后会影响自适应学习率并增加训练比值噪声，因此改用TF32作默认设置，并保留另一种精度路径。这说明训练设置更省显存或更低精度，不一定就更稳或更快。[混合精度修复](https://github.com/Denys88/rl_games/pull/383)、[机器鸭训练讨论](https://github.com/Denys88/rl_games/pull/372)

2026年10月29日首次入表并列入重点：它给出了不同训练器的可检查比较和明确问题，值得跟踪。补查范围为最近30天的问题、回复及可取得的版本资料，未执行项目代码，也不把训练器Star当作机器鸭使用者数。
