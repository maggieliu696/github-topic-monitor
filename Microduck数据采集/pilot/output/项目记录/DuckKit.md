# DuckKit｜让 Swift 应用也能调用鸭子的动作和控制接口

名单选择号：78。方向：让安装、控制和开发更容易。作者／发布账号：**craigm26**。资料整理日期：2026 年 10 月 26 日。

## 项目做什么

用 Swift 封装鸭子的动作模型、身体计算、声音和控制协议，让开发者把这些能力接入自己的应用。需要签名和记录凭证的部分单独提供，不强迫普通应用一起安装。 [项目说明](https://github.com/craigm26/duckkit)

代码或制作资料已在 GitHub 公开。**Star：6**，采集于 2026-10-26 16:43（北京时间）。说明中的接入示例使用 1.0.0 标签；未核实最新发行版。 [仓库数据](https://api.github.com/repos/craigm26/duckkit)

## 目前做到哪一步

作者称可以运行官方行走模型，并把计算结果与原模型执行工具比较；测试覆盖 Linux 和 macOS，记录为 347 项测试。示例依赖标签从 1.0.0 起，项目还区分动作、外形显示和签名三个用途。 [项目说明](https://github.com/craigm26/duckkit)

## 遇到了什么问题，怎样处理

这些测试不依赖真实机器人，也不是实体行走验证。项目特别保留官方关节顺序、默认姿态和动作缩放，避免参数看似合理却让动作出错。本轮未取得独立应用使用者的长期反馈。 [项目说明](https://github.com/craigm26/duckkit)
